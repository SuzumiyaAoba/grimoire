# grimoire

AI の外部メモリーと知識更新に関する調査資料をまとめています。会話・文書・ツール結果から知識を蓄積し、根拠を保ちながら更新するシステムを検討します。

- [調査の概要と目次](docs/research/README.md): 調査から得られた判断と、目的別の読み方。
- [オントロジー・ナレッジシステムの推奨設計](docs/design/ontology-knowledge-system.md): 技術スタック、構成、データモデル、三つの用途への適用、実装順序。
- [設計の選択肢と研究計画](docs/research/design-directions.md): 調査に基づく設計仮説と比較実験の案。
- [ドキュメントガイド](docs/README.md): 文書の配置と追加・更新のルール。

対象版、確認日、検証範囲は各資料と[調査方法](docs/research/methodology.md)に記載しています。
